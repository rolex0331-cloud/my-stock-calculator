# 오혜야 API 대기모드 V1

쿠팡 파트너스 API 승인 전에도 운영 가능한 정적 MVP입니다.

## 포함 기능
- 홈 / 검색 / 카테고리 / 특가 필터 / 정렬
- 오혜야 점수 자동 계산
- 데이터 신선도 경고(7일 초과)
- 찜(localStorage)
- 상품 상세 / 판매처 이동 클릭 집계
- 관리자 상품 등록·수정·삭제
- 후보 큐 승인·보류·제외
- CSV 일괄 등록 및 양식 다운로드
- JSON 전체 백업·복원
- 쿠팡 API 교체를 고려한 필드 구조

## 쿠팡 API 승인 후
브라우저에 Secret Key를 넣지 말고, 서버/서버리스 함수에 Access Key와 Secret Key를 환경변수로 보관하세요. 서버에서 쿠팡 응답을 현재 상품 스키마로 정규화한 뒤 프런트에 전달하면 UI는 그대로 사용할 수 있습니다.

## 주의
기본 상품은 동작 확인용 샘플이며 실시간 판매 가격을 의미하지 않습니다.
